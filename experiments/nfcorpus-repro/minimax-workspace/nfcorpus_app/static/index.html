        5 · Deployment contract

        • Docker web service that binds 0.0.0.0 and reads the PORT env var (defaults to 10000).
        • GET /health returns JSON with status, anserini_available, nfcorpus_ready, search_available, and evaluation_available.
        • No interactive setup is required after the container starts; the fatjar is downloaded during the first readiness probe.
        • Runtime caches live under ./data; mount a Render persistent disk at that path to keep them across deploys.
        • Only the NFCorpus subset of the BEIR prebuilt index is downloaded (~6.2 MB). The full BEIR archive is never fetched.
