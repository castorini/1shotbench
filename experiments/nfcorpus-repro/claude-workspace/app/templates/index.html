    Docker / Render readiness contract
    
      
      
        
    • Container binds 0.0.0.0 on PORT.
      • 
        
    • Default PORT when unset: 10000 (Render convention).
      • 
        
    • Health endpoint: /health returns JSON with anserini, nfcorpus, search and evaluation flags.
      • 
        
    • Cache directory: cache/. Persistent disk should mount here on Render.
      • 
        
    • No interactive setup after container start; setup runs in a background thread.
      • 
        
    • No whole-BEIR or MS MARCO downloads — only the ~7 MB NFCorpus prebuilt index is fetched.
