Deployment Notes

This application is designed as a single Docker web service for Render.

  • HTTP binds to 0.0.0.0 and respects the PORT environment variable (defaults to 10000).
  • Runtime caches and generated artifacts are stored under /app/cache inside the container.
  • The container is self-contained: it downloads the Anserini fatjar on first startup and caches the NFCorpus prebuilt index via Anserini’s built-in cache.
  • No interactive setup is required after the container starts.
