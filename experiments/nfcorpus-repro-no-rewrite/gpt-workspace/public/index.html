Docker / Render Readiness Contract

      
    
        
  • Container binds HTTP to 0.0.0.0 and reads PORT, defaulting to 10000.
    • 
        
  • /health returns JSON with app status, Anserini availability, NFCorpus readiness, search availability, and evaluation availability.
    • 
        
  • Runtime cache defaults to .cache; on Render, mount persistent disk at /data/nfcorpus-workbench and set APP_CACHE_DIR accordingly.
