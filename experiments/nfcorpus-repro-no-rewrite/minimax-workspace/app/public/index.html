Live search over NFCorpus

Each query is served by the Anserini REST server backed by the beir-v1.0.0-nfcorpus.flat prebuilt index. Result rows include rank, docid, BM25 score, title, and the full indexed text.

    BM25 evaluation

    Anserini runs SearchCollection over the beir-nfcorpus test topics with BM25, writes a TREC run file, and evaluates it with io.anserini.eval.TrecEval. The table below shows observed vs. expected metrics.
